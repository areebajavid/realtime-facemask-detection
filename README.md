# deepface-mask-detection
This project implements a Face Mask Detection System using Convolutional Neural Networks (CNN) and the VGG16 architecture in Keras. The primary goal is to create a reliable and efficient system that can accurately classify individuals as wearing a mask or not.
Features:
High Accuracy: Achieved up to 96% accuracy for face mask detection by leveraging transfer learning with the VGG16 model.
Face Detection: Enhances mask detection performance by focusing solely on facial regions using Haar Cascade for frontal face detection.
Real-Time Processing: Capable of processing video frames for mask detection, making it suitable for real-world applications.
